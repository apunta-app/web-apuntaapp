# web-apuntaapp

Web oficial de **Apunta** — apuntaapp.com

App de gestión de facturas para autónomos. Una app de Evolution Studios S.L.

## Estructura del proyecto

```
web-apuntaapp/
├── index.html                    Página principal
├── politica-privacidad.html      Política de privacidad (RGPD)
├── aviso-legal.html              Aviso legal (LSSI-CE)
├── terminos-condiciones.html     Términos y condiciones de uso
├── styles.css                    Estilos CSS
├── logo-apunta.png               Logo de Apunta (pendiente añadir)
├── favicon.png                   Favicon (pendiente añadir)
├── CNAME                         Dominio personalizado para GitHub Pages
└── capturas/                     Capturas de pantalla de la app
    ├── 01-dashboard.png
    ├── 02-confirmacion-ocr.png
    ├── 03-historial.png
    └── 04-exportar.png
```

## Tecnologías

- HTML5 semántico
- CSS3 puro (sin frameworks)
- Sin JavaScript (sitio estático)
- Responsive design (móvil, tablet, escritorio)

## Despliegue

Esta web está alojada en GitHub Pages con dominio personalizado **apuntaapp.com**.
